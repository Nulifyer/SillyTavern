# SillyTavern

Dark character roleplay workspace built on SillyTavern.

Browse characters, read a profile, and start or resume a scene. Manage stories in
Chats and Archive, create casts, and use image and voice tools beside the composer.
Advanced settings keep their native controls. Classic layout remains available.

- [User stories and reference review](docs/roleplay-workspace.md)
- [Original UI map and workspace design](docs/workspace-design.md)
- [Release images and homelab updates](docs/container-releases.md)

Published GitHub Releases build amd64 and arm64 containers:

```yaml
image: ghcr.io/nulifyer/sillytavern:latest
```

Keep existing SillyTavern config, data, plugin, and extension volumes.
