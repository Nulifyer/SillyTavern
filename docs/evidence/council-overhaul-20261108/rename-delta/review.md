# Rename and character ownership correction

The actual v1.19.22 image passed 92 of 93 browser cases. The identical-filename
case lost its original user draft. Eight traced repetitions passed, which does
not disprove that failure or establish its exact untraced sequence.

A controlled reproduction then held the native character definition write after
the file rename succeeded, refreshed the visible title and typed a turn. Releasing
the write cleared that turn on v1.19.22. The replacement preserves it. Separate
controlled tests show that v1.19.22 clears the live character collection while
JSON is pending and leaves it empty after malformed data. Those cases pass with
staged publication. Before and after logs/results are retained in this directory.

The native CHAT_RENAME_ACKNOWLEDGED event announces file acknowledgement before
metadata persistence and reload. It does not claim metadata persistence succeeded.
CHAT_RENAMED keeps its existing completion timing. BrowserRecovery owns one
bounded draft transition, full account/entity identity and conflict preservation.
Native CHAT_CHANGED retires old-name permission; a distinct incarnation cannot
lend its composer or native pointer to an earlier rename. No character reply is
stored or inserted as a draft and no generation is replayed.

Character refresh parses, validates stable avatar identifiers and normalizes a
complete candidate before replacing the shared list. Pending or invalid data
preserves the last valid owner and mounted conversation. This is not a new
character registry or a backend transaction layer.

The final focused run passed eight cases in 43.9 seconds. It covers delayed and
failed character/cast metadata, the original sibling-filename draft isolation,
pending JSON, five malformed collection shapes, and the native override footer
at computed font scale 1.5 with a 20px browser root at 320 by 400. The unit suite
passes 494 tests in 26 suites. Root lint and actionlint pass. Test lint reports
zero errors and 53 warnings. The 19-file runtime manifest identifies these bytes.

Two full v1.19.23 source attempts were interrupted for the council's avatar,
transition-lifetime and stored-draft corrections. Their partial artifacts remain
in source-superseded and source-superseded2-browser.
The final combined source and actual-image runs are recorded separately. Source
overlays and focused results alone do not qualify release acceptance.
